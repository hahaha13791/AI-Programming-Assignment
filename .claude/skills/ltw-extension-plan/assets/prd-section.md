### 4-<X>. <이름> (확장 <N>)

<한두 문장: 사용자가 무엇을 듣고 무엇을 적는지(또는 무엇을 하는지). 범위의 틀(조성, 음역, 박자, 음표 종류, 최대 개수)과 지원하지 않는 것도 여기서 한 번에 적는다.>

1. 사용자는 <무엇을 고르거나 준비한다>.
   - <세부 규칙: 저장, 검증, 실패 시 안내, 안내 문구 자리 고정>
   - <패널 높이: 다른 모드와 같아 받아 적기 영역이 움직이지 않는다 (4-0-3)>
2. 사용자는 <듣기: 무엇을, 어떤 순서·빠르기로(♩= 80 등)>. 처음 끝까지 들은 뒤에 입력이 열린다.
   - <다시 듣기, 펼쳐 듣기 등 추가 재생 규칙>
3. 사용자는 <입력 방법: 오선 클릭 / 음표 버튼 / …>으로 <무엇을> 적는다.
4. 사용자는 제출하면 <채점 단위>별 정답/오답과 함께 <정답 공개 방식>을 확인한다. "다음 문제"는 <다음에 무엇이 나오는지>.

#### 진행 흐름
- <고르기> → <기준음/카운트인> → <재생> → <입력> → 제출 → <채점 + 정답 공개> → 다음 문제
